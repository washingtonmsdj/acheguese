# 🍽️ Guia Rápido - Características Dietéticas

## 📖 Para Administradores

### Como Cadastrar um Produto com Características Dietéticas

1. **Acesse o Painel de Gestão**
   - Menu → Gastronomia → Gestão de Cardápio

2. **Crie ou Edite um Item**
   - Clique em "Novo Item" ou edite um existente

3. **Preencha as Informações Básicas**
   - Nome, descrição, preço, categoria

4. **Configure as Características Dietéticas**
   
   #### Switches Disponíveis:
   - 🥬 **Vegetariano** - Não contém carne
   - 🌱 **Vegano** - Não contém produtos de origem animal
   - 🌾 **Sem Glúten** - Não contém trigo, centeio, cevada
   - 🥛 **Sem Lactose** - Não contém leite e derivados
   - 🌶️ **Picante** - Contém pimenta ou temperos picantes
     - Se marcar "Picante", defina o nível (1-5)

5. **Adicione Informações Nutricionais**
   - **Calorias**: Valor calórico aproximado (ex: 850)
   - **Tempo de Preparo**: Em minutos (ex: 25)

6. **Liste os Ingredientes**
   - Digite separado por vírgula
   - Exemplo: `mussarela, tomate, manjericão, azeite`

7. **Informe os Alérgenos**
   - Digite separado por vírgula
   - Exemplo: `glúten, lactose, amendoim`
   - ⚠️ **Importante**: Alérgenos aparecem destacados para os clientes

8. **Salve o Item**

## 👥 Para Clientes

### Como Filtrar Produtos por Características Dietéticas

1. **Acesse a Página do Restaurante**
   - Navegue até o estabelecimento desejado

2. **Use os Filtros**
   - Abaixo das categorias, você verá botões de filtro:
     - 🌱 **Vegano**
     - 🥬 **Vegetariano**
     - 🌾 **Sem Glúten**
     - 🥛 **Sem Lactose**

3. **Clique nos Filtros Desejados**
   - Pode selecionar múltiplos filtros
   - Os produtos são filtrados em tempo real

4. **Visualize os Badges nos Produtos**
   - Cada produto mostra suas características com badges coloridos

5. **Veja Detalhes Completos**
   - Clique no produto para ver:
     - Lista completa de ingredientes
     - Alérgenos (destacados em amarelo)
     - Calorias
     - Nível de picância (se aplicável)

## 🆘 Dúvidas Frequentes

### Para Administradores:

**P: Preciso preencher todos os campos?**  
R: Não! Todos os campos são opcionais. Preencha apenas o que for relevante.

**P: Posso mudar as informações depois?**  
R: Sim! Você pode editar a qualquer momento.

**P: O que acontece se eu não preencher os alérgenos?**  
R: O campo ficará vazio, mas é **altamente recomendado** preencher para segurança dos clientes.

**P: Como funciona o nível de picância?**  
R: É uma escala de 1 a 5:
- 1 = Levemente picante
- 2 = Picante suave
- 3 = Picante médio
- 4 = Muito picante
- 5 = Extremamente picante

---

### Para Clientes:

**P: Os filtros são confiáveis?**  
R: As informações são fornecidas pelo estabelecimento. Em caso de alergias graves, sempre confirme diretamente.

**P: Posso usar múltiplos filtros?**  
R: Sim! Você pode combinar filtros (ex: Vegano + Sem Glúten).

**P: O que significa "Sem Glúten"?**  
R: Significa que o prato não contém trigo, centeio, cevada ou outros cereais com glúten.

**P: Vegano é diferente de Vegetariano?**  
R: Sim!
- **Vegetariano**: Não contém carne
- **Vegano**: Não contém nenhum produto de origem animal (carne, leite, ovos, mel, etc.)
