# community-feed

Modulo transversal para o feed territorial.

Boundary:
- Consome somente `core/posts`, `core/comments`, `core/social`, `core/feed`, `core/location` e facades de `core/community` ainda em migracao.
- Nao importa outros modulos `src/modules/*`.
- O territorio e sempre resolvido por `location_id` via core.
