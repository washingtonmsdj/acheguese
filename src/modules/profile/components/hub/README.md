# Hub Components - Componentes Modulares do Perfil

Componentes reutilizáveis e modulares que sustentam o hub de conta/perfil.

---

## Componentes disponíveis

### ProfileHeaderCompact
Cabeçalho principal do hub com identidade resumida, status da conta e ações rápidas.

### ProfileStats
Cards de estatísticas visuais com animações.

### SectionFrame
Container consistente para seções do hub com título, descrição e ação opcional.

### HubLinkCard
Card de link/ação reutilizável para navegação no hub.

### EmptyPanel
Estado vazio genérico com mensagem e call-to-action.

### NextActionsPanel
Painel de próximas ações recomendadas para completar onboarding e reduzir fricção.

### BusinessModulesSection
Seção de módulos empresariais com visão operacional consolidada.

### ContentTabsSection
Seção de conteúdo com tabs para dados relacionados ao perfil.

### NotificationsPanel
Painel de notificações recentes do perfil.

### AccountHealthPanel
Painel de saúde da conta com estado, plano, reputação e permissões.

### ProfileSectionsNav
Navegação responsiva das seções, em sidebar no desktop e tabs no mobile.

### ProfileSidebarHeader / ProfileSidebarFooter
Blocos auxiliares usados pela navegação lateral do hub.

**Total:** 11 componentes ativos no hub
