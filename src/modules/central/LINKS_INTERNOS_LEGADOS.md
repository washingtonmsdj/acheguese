# Links Internos Legados

Estado atual: nao ha links legados ativos no runtime para a separacao Perfil, Central e Empresas.

Rotas canonicas:

- Perfil pessoal: `/perfil`.
- Central operacional: `/central`.
- Criacao real de empresa: `/central/empresas/nova`.
- Landing comercial de cadastro: `/empresas/cadastrar`.
- Descoberta publica de empresas: `/empresas`.

Regra de manutencao:

- Nao adicionar redirects temporarios.
- Nao apontar CTA operacional para `/empresas`.
- Nao adicionar formulario administrativo dentro do modulo publico de empresas.
- Corrigir links antigos na origem, usando os helpers de SSOT.
