# Game 03 — Voxel Sandbox (Three.js puro)

## Objetivo (MVP)
- Recriar base estilo Minecraft/Roblox **sem Ordax engine**
- Mundo voxel **procedural**
- **1 player** com controles FPS (Pointer Lock)

## Controles
- Clique: trava o mouse (Pointer Lock)
- WASD: mover
- Shift: correr
- Space: pular
- ESC: destravar

## Próximos passos (incremental)
1. Colocar/quebrar blocos (raycast + instancing)
2. Colisão AABB do player com blocos
3. Inventário + hotbar
4. Chunks + streaming
