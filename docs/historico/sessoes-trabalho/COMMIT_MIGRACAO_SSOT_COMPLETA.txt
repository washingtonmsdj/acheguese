## SSOT Hooks Created

1. **useAppUrls** - Central hook aggregating all modules
   - Auth URLs (login, register, onboarding)
   - Profile URLs (central, public, manage, edit)
   - Global URLs (home, settings, messages, etc.)
   - Family URLs (home, alerts, zones, settings)

2. **useBusinessUrls** - Business module (territorial)
   - list, portal, create, edit, dashboard

3. **useServiceUrls** - Services module (territorial)
   - list, detail, create, edit

4. **useClassifiedUrls** - Classifieds module (territorial)
   - list, detail, create

5. **useCommunityUrls** - Community module (territorial + global)
   - feed, events, groups, recommendations, lostAndFound, coupons

6. **useMobilityUrls** - Mobility module (NEW)
   - home, passenger, driver, driverProfile, history

## Migration Pattern

```typescript
// Before
navigate("/login");
navigate(`/business/${slug}`);

// After
const appUrls = useAppUrls();
navigate(appUrls.auth.login);
navigate(appUrls.business.portal(slug));
```
