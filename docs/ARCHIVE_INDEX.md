# Indice do Arquivo Historico

Este indice centraliza documentacao arquivada e material que nao rege mais o estado atual do projeto.

## Arvores historicas
- `docs/archive/cleanup/`: limpezas e consolidacoes anteriores
- `docs/archive/phases/`: fases tecnicas antigas
- `docs/archive/status/`: snapshots de status e planejamento
- `docs/archive/type-safety/`: relatorios antigos de type safety
- `docs/archive/root-legacy/`: lote legado reorganizado a partir da raiz
- `docs/historico/`: historico consolidado de fases e entregas
- `docs/historico/architecture-fix/`: pacote historico de correcao arquitetural movido para historico

## Regra
1. Documento vivo fica em `docs/` ou no dominio dono.
2. Sessao, entrega datada, snapshot ou comparativo vai para `docs/archive/`.
3. Arvore historica consolidada sem vigencia atual vai para `docs/historico/`.
