# Handoff de continuidade

Esta pasta contem handoffs operacionais para outra IA ou desenvolvedor retomar
trabalho sem depender do historico da conversa.

## Como usar

1. Leia primeiro o handoff mais recente e siga as precondicoes descritas.
2. Verifique `git status --short` antes de editar: este repositorio pode conter
   mudancas locais de outras frentes.
3. Nao agrupe mudancas nao relacionadas no mesmo commit.
4. Execute todos os gates indicados antes de aplicar migration ou publicar.
