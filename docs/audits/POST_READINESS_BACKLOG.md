# Itens para Pos-Prontidao do Sistema

## Adiar ate a base estar blindada
- redesenho profundo de experiencia social/comunidade
- expansao de novos modulos publicos
- novas variacoes de landing ou rotas premium
- refatoracao estetica ampla sem contrato visual base aprovado
- crescimento de automacoes administrativas sem matriz de ownership
- aumento de canais de notificacao antes de fechar o SSOT do dominio
- evolucao funcional de delivery enquanto gastronomia x business x delivery ainda nao estiverem formalmente separados
- reabertura de novos wrappers de compatibilidade para acelerar integracao

## Pode entrar depois da prontidao
- design system mais amplo de templates e tokens de superficie
- cobertura administrativa analitica avancada por dominio
- automacao de relatorio executivo gerado por script a partir do inventario
- revisao de mocks para fixture catalog por ambiente
- simplificacao fina de routes legadas remanescentes apos a migracao principal
