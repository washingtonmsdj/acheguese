## 📐 Padrões Estabelecidos

### Padding dos Cards
```css
p-3  /* 12px - padrão para todos os widgets */
```

### Headers
```css
mb-3           /* 12px - espaçamento após header */
w-7 h-7        /* 28px - tamanho do ícone */
text-sm        /* 14px - tamanho do título */
```

### Espaçamento entre Items
```css
space-y-1.5    /* 6px - para items compactos */
space-y-2      /* 8px - para items com mais conteúdo */
```

### Padding dos Items
```css
p-2            /* 8px - padrão para items clicáveis */
```

### Gap entre Elementos
```css
gap-2          /* 8px - padrão para elementos horizontais */
gap-2.5        /* 10px - para elementos que precisam mais espaço */
```

### Avatares
```css
h-7 w-7        /* 28px - avatares pequenos (ranking, atividades) */
h-9 w-9        /* 36px - avatares médios (grupos, sugestões) */
h-11 w-11      /* 44px - avatar grande (perfil) */
```

### Botões CTA
```css
mt-2.5         /* 10px - espaçamento antes do botão */
h-8            /* 32px - altura do botão */
text-xs        /* 12px - tamanho do texto */
```
