# Root Legacy Docs

Este diretorio concentra documentos legados que estavam soltos na raiz do repositorio.
A organizacao foi feita por prefixo de nome de arquivo para manter rastreabilidade sem perder historico.

Total movido da raiz em 2026-04-09: 1015 arquivos

## Estrutura
- Cada subpasta representa o prefixo do arquivo original em minusculo.
- O mapeamento completo esta em `MOVE_LOG.csv`.
- `README.md` e `SECURITY.md` permanecem na raiz por convencao de projeto.
