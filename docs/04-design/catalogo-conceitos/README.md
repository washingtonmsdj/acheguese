## Como navegar

Cada pasta corresponde a uma página ou fluxo, com README próprio, imagens de referência e histórico. “Referência para revisão” é seleção editorial para comparação, não aprovação automática nem prova de implementação. As versões anteriores permanecem em historico/. Não implemente o histórico por cima da referência.

As descrições das páginas antigas foram reconstruídas pela leitura das pranchas e do contexto; não representam uma auditoria integral do código. Documentos anteriores disponíveis foram preservados na pasta documentos-originais/. O próximo chat deve conferir o código atual antes de aplicar.

Abra index.html para navegar visualmente. Consulte manifest.json para origem, nome, classificação e SHA-256 de cada imagem.
